## 📖 About The Project

**AutoCare** is a web-based car maintenance management platform that connects **car owners**, **certified service centers**, and **platform admins** in one place.

Owners build a digital garage, log their odometer readings, and let the system calculate oil life and service intervals _before_ a breakdown happens. They can then browse vetted workshops, book a service slot, and keep a permanent record of every invoice and expense. Workshops get a simple dashboard to manage branches, accept or reject bookings, and issue digital invoices, while admins oversee the whole network.

> 💡 **In one line:** _AutoCare is your car's digital garage and your workshop's booking desk, in one smart platform._

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org) (LTS version)
- npm (comes with Node.js)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/ahmeddemad15/AutoCare.git

# 2. Go into the project folder
cd AutoCare

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

Then open the local URL printed in your terminal (usually `http://localhost:5173`). 🎉

> ⚠️ **Seeing `'vite' is not recognized`?** You skipped `npm install`. Run it first, in the folder that contains `package.json`.
